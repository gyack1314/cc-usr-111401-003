# 资料与既有接口约定

日志项含 epoch、offset、previous、manifest；previous 是前项规范摘要，首项 previous=null。manifest 列出全部对象 SHA256，不以文件名相同推断内容相同。通道分别递送日志及对象，可乱序和重复。接管授权来自本地 authority.json，包含递增 epoch 和允许持有者，非网络选举协议。接收端只能在已授权世代上推进；世代切换须以明确基准提交相接。replica.py 已能独立落地消息和对象，尚未提供可读头或接管。

所有资料均为合成，字段、身份及状态按本文解释。源码中的 inspect 入口只读取并核对现有基础接口；不会建立高级查询或仓库管理流程。
